# hoodoocrawfish.com

Website for Hoodoo Crawfish Catering Co. (Austin, TX). Static HTML with no dependencies, deployed by GitHub Pages.

- `site.config.mjs`: every business fact (phone, rating, prices, weekday offer, public events). Edit here first.
- `src/pages/*.mjs`: one file per page, or a few related pages together. Copy is plain HTML in template strings.
- `src/layout.mjs`, `src/lib.mjs`, `src/style.css`: shared shell, components, styles.
- `public/img/`: optimized WebP photos, generated by `tools/images.py` from the old site's originals.

```
node build.mjs                 # -> dist/
python3 -m http.server -d dist # preview at http://localhost:8000
```

The build fails if any page doesn't have exactly one `<h1>`, and warns on over-long titles and descriptions.
Pushing to `main` deploys. See **LAUNCH.md** for the owner checklist and the domain cutover.
